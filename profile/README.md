# PCCX · Parallel Compute Core eXecutor

**Open-source NPU and FPGA research, initiated and operated by Altifigence.**

PCCX connects architecture and ISA documentation, reusable SystemVerilog RTL,
verification and board integration. We welcome reproducible experiments,
focused fixes, tests and documentation contributions.

[Website](https://pccx.ai/) · [Documentation](https://docs.pccx.ai/en/)

## Find your repository

| Repository | Role |
| --- | --- |
| [pccx](https://github.com/pccxai/pccx) | Architecture, ISA, implementation notes, evidence and contribution guidance |
| [pccx-v002](https://github.com/pccxai/pccx-v002) | Reusable v002 IP-core sources and compatibility contracts |
| [pccx-FPGA-NPU-LLM-kv260](https://github.com/pccxai/pccx-FPGA-NPU-LLM-kv260) | KV260 board/model integration consuming a pinned v002 core |
| [pccx-v003](https://github.com/pccxai/pccx-v003) | Next-generation implementation and experimental smoke paths; hardware results require separate evidence |

The dated KV260 deployment snapshot is retained for historical artifacts and
debug provenance. New contributions should start in an active repository above.

## Join in

1. Read the [first-check guide](https://github.com/pccxai/pccx/blob/main/START_HERE.md).
2. Pick an existing issue or ask in [Discussions](https://github.com/pccxai/pccx/discussions).
3. Submit a small PR with the source revision, command, expected result and logs.

Simulation, synthesis, implementation and measured board behavior are different
evidence. We do not treat a smoke pass as a completed model or throughput result.
